# MedRP · SAMU 93 — vLifeRoleplay

Boîte à outils médicale pour le roleplay SAMU 93 sur vLifeRoleplay.

**Site :** https://poli-21.github.io/RPIDE/

## Contenu

- **Macros /me et /qu** — plus de 200 actions et questions prêtes à copier, classées par catégorie, avec favoris et création de macros perso.
- **Schéma corporel** — clic sur une zone du corps pour obtenir les gestes possibles et le /me correspondant.
- **Procédures guidées** — les gestes techniques étape par étape, dans le bon ordre.
- **Faire ma perfusion** — atelier de préparation en 6 étapes (poids, médicament, solvant, dilution, purge, débit) avec calculs réels de mL/h et de gouttes/min, contrôle des incompatibilités, et un mode examen de 12 cas cliniques notés.

## Technique

Une seule page autonome : `index.html`. React et Babel sont chargés depuis un CDN, aucune installation n'est nécessaire — ouvrir le fichier suffit. Les macros perso, les favoris et les scores d'examen sont stockés dans le navigateur (localStorage).

## Avertissement

Outil de roleplay. Les protocoles s'inspirent de la pratique préhospitalière réelle mais ce projet n'a aucune valeur médicale et ne doit jamais servir de référence de soin.
